# Usage statistics

The repository owner maintains the detailed traffic history privately.
The dataset and its versioned release ZIP remain publicly available.

GitHub exposes download counters for explicitly uploaded release assets.
Repository clones, page views, and release downloads are different metrics;
they should not be combined into a single download count.

See the [dataset release](https://github.com/AdamLiang42/SynResLoadPattern/releases/latest)
or the [GitHub release-assets API documentation](https://docs.github.com/en/rest/releases/assets).
